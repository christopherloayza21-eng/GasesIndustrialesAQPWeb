# Gases Industriales AQP Web

Sitio web corporativo para Gases Industriales AQP, enfocado en presentar servicios de gases industriales, recarga de cilindros, equipos de soldar, insumos de soldadura y canales de contacto en Arequipa.

## Estado del proyecto

Proyecto en desarrollo. La primera version esta construida con HTML y CSS puro para mantener una base simple, entendible y facil de mejorar.

## Paginas actuales

- `index.html`: pagina principal y presentacion comercial.
- `gases.html`: gases industriales, recarga, canje y venta de cilindros.
- `productos.html`: equipos de soldar y soldadura/insumos.
- `nosotros.html`: informacion de la empresa, enfoque operativo y confianza.
- `contacto.html`: datos de contacto, puntos de atencion y telefonos.

## Tecnologias usadas

- HTML5
- CSS3
- Enlaces directos a WhatsApp
- Diseno responsive basico
